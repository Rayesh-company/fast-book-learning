# تحویل و اتصال دوبارهٔ صوت جلسات به کتاب‌خوان

این راهنما برای نسخهٔ فعلی پروژه و کتاب «طرح کلی اندیشۀ اسلامی در قرآن» با شناسهٔ `tarhe-kolli` است. بسته شامل ۲۸ فایل MP3 اصلی جلسات و نسخهٔ متناظر فایل زمان‌بندی است. صوت‌ها بازفشرده یا ویرایش نشده‌اند.

## محتویات بسته

```text
fast-book-lecture-audio.zip
├── books/
│   ├── tarhe-kolli.lectures.json
│   └── tarhe-kolli/lectures/
│       ├── session_01.mp3
│       ├── session_02.mp3
│       └── … session_28.mp3
├── SHA256SUMS
└── README.fa.md
```

فایل JSON، شمارهٔ جلسات، نام صوت‌ها، زمان کلمات و محدودهٔ متن روی صفحات PDF را نگه می‌دارد. برای نمایش هایلایت و ورق‌زدن همگام، هم فایل صوت و هم این فایل لازم‌اند. بسته PDF را شامل نمی‌شود؛ همان نسخهٔ PDF سازگار باید در پروژه با نام `books/tarhe-kolli.pdf` موجود باشد. مشخصات PDF مورد استفاده در بخش `source` فایل JSON ثبت شده است.

نام فایل‌ها و شناسهٔ کتاب را تغییر ندهید. کوتاه‌کردن مقدمه، تغییر سرعتِ خود فایل یا جایگزینی ضبط دیگری، زمان‌بندی را نامعتبر می‌کند. انتخاب سرعت یا «بدون مقدمه» در پلیر مجاز است و فایل را تغییر نمی‌دهد.

## روش اول: برگرداندن فایل‌ها داخل پروژه

۱. فایل ZIP را در یک پوشهٔ موقت استخراج کنید.

۲. سرور پروژه را متوقف کنید. پوشهٔ `books` داخل بسته را با پوشهٔ `books` پروژه ادغام کنید. اگر نسخهٔ دیگری از فایل JSON دارید، پیش از جایگزینی از آن کپی پشتیبان بگیرید. نتیجه باید دقیقاً چنین باشد:

```text
fast-book-learning/
├── ui/
└── books/
    ├── tarhe-kolli.pdf
    ├── tarhe-kolli.lectures.json
    └── tarhe-kolli/lectures/session_01.mp3 … session_28.mp3
```

۳. از ریشهٔ پروژه اجرا کنید. اگر قبلاً متغیرهای صوت را تنظیم کرده‌اید، برای این روش آن‌ها را حذف کنید تا فایل‌های داخل پروژه استفاده شوند:

```bash
unset LECTURE_AUDIO_DIR LECTURE_AUDIO_BASE_URL
python3 ui/mobile/share.py --host 0.0.0.0 --port 8766 --books-dir books
```

در ویندوز با PowerShell:

```powershell
Remove-Item Env:LECTURE_AUDIO_DIR, Env:LECTURE_AUDIO_BASE_URL -ErrorAction SilentlyContinue
python ui/mobile/share.py --host 0.0.0.0 --port 8766 --books-dir books
```

۴. آدرس `http://localhost:8766/mobile/?demo=1` را باز کنید. برای گوشی، به‌جای `localhost`، IP شبکهٔ کامپیوتر را بگذارید؛ هر دو دستگاه باید در یک شبکه باشند. در لینوکس `hostname -I` و در ویندوز `ipconfig` آدرس را نشان می‌دهد.

۵. کتاب را باز کنید و از پلیر مرکزی پایین صفحه استفاده کنید. با بازکردن پلیر می‌توانید جلسه، سرعت و گزینهٔ «بدون مقدمه» را انتخاب کنید. کنترل هدفون جداگانه در رابط فعلی وجود ندارد.

## روش دوم: نگهداری صوت‌ها بیرون از مخزن

در این روش JSON همچنان باید داخل `books` پروژه باشد، اما MP3ها می‌توانند بیرون پروژه بمانند؛ مثلاً:

```text
/home/USER/BookAudio/
└── tarhe-kolli/
    ├── session_01.mp3
    └── … session_28.mp3
```

پوشهٔ `lectures` داخل بسته را به `tarhe-kolli` در محل بالا کپی کنید؛ یک لایهٔ اضافی به نام `lectures` ایجاد نکنید. سپس:

```bash
unset LECTURE_AUDIO_BASE_URL
python3 ui/mobile/share.py --host 0.0.0.0 --port 8766 --books-dir books \
  --lecture-audio-dir /home/USER/BookAudio
```

در ویندوز نمونهٔ مسیر می‌تواند `D:\BookAudio` باشد:

```powershell
Remove-Item Env:LECTURE_AUDIO_BASE_URL -ErrorAction SilentlyContinue
python ui/mobile/share.py --host 0.0.0.0 --port 8766 --books-dir books --lecture-audio-dir "D:\BookAudio"
```

سرور در پوشهٔ مشخص‌شده ابتدا `tarhe-kolli/session_01.mp3` و سپس `session_01.mp3` را جستجو می‌کند. وقتی این تنظیم فعال است، به صوت‌های داخل پروژه برنمی‌گردد؛ پس مسیر نادرست باعث «بدون صوت» می‌شود.

برای سرور اصلی `ui/serve.py` نیز متغیر `LECTURE_AUDIO_DIR` همین کار را می‌کند. مسیرهای جلسات در سرور اصلی به ورود حساب نیاز دارند؛ میزبان پیش‌نمایش بالا برای آزمایش محلی است.

## اجرای Docker

روش اول با نگاشت موجود `./books:/books:ro` در `compose.yaml` کار می‌کند. فایل‌ها باید روی میزبان داخل `books` باشند. اگر از روش دوم استفاده می‌کنید، پوشهٔ خارجی را هم داخل کانتینر mount کنید و `LECTURE_AUDIO_DIR` را به مسیر داخل کانتینر تنظیم کنید، نه مسیر میزبان. تنظیم فقط در `.env` بدون mount کافی نیست. پس از تغییر تنظیمات کانتینر، سرویس مربوط را دوباره ایجاد کنید.

## بررسی اتصال

هنگام اجرای میزبان پیش‌نمایش، آدرس زیر باید فهرست ۲۸ جلسه را برگرداند و مقدار `audio_available` برای همه `true` باشد:

```text
http://localhost:8766/books/tarhe-kolli/lectures
```

اطلاعات جلسهٔ اول:

```text
http://localhost:8766/books/tarhe-kolli/lectures/1
```

مقدار `audio_url` باید `/books/tarhe-kolli/lectures/1/audio` باشد. فایل JSON نباید دستی برای افزودن این مقدار ویرایش شود؛ سرور آن را می‌سازد. پخش مستقیم جلسهٔ اول را نیز می‌توانید از همین آدرس امتحان کنید.

برای بررسی جست‌وجوی زمان روی لینوکس:

```bash
curl -s -D - -o /dev/null -H 'Range: bytes=0-1023' \
  http://localhost:8766/books/tarhe-kolli/lectures/1/audio
```

انتظار می‌رود وضعیت `206 Partial Content`، نوع `audio/mpeg` و طول `1024` برگردد. این بررسی برای جلو و عقب رفتن در صوت مهم است.

## بررسی سلامت بسته

پس از استخراج، در همان پوشه‌ای که `SHA256SUMS` وجود دارد اجرا کنید:

```bash
sha256sum -c SHA256SUMS
```

همهٔ فایل‌ها باید `OK` شوند. فایل `manifest.json` کنار ZIP نیز اندازه، مدت و SHA-256 هر جلسه را ثبت می‌کند. `PACKAGE.sha256` برای بررسی خود ZIP است.

## رفع مشکل‌های رایج

| نشانه | بررسی و راه‌حل |
|---|---|
| جلسه‌ها دیده نمی‌شوند | وجود `books/tarhe-kolli.lectures.json` و مقدار درست `--books-dir` را بررسی کنید. |
| جلسه دیده می‌شود ولی «بدون صوت» است | نام دقیق MP3، مسیر پوشه و تنظیم `LECTURE_AUDIO_DIR` را بررسی کنید. |
| سرور به آدرس اینترنتی ناموجود اشاره می‌کند | متغیر `LECTURE_AUDIO_BASE_URL` را حذف کنید؛ اگر مقدار داشته باشد، بر مسیر محلی اولویت دارد. |
| صوت پخش می‌شود ولی هایلایت یا صفحه اشتباه است | از همین MP3ها، همین JSON و PDF سازگار استفاده کنید؛ نسخهٔ کوتاه‌شدهٔ صوت یا PDF با صفحه‌بندی متفاوت جایگزین نکنید. |
| گوشی وصل نمی‌شود | سرور با `--host 0.0.0.0` اجرا شود؛ IP کامپیوتر درست باشد و فایروال دسترسی شبکهٔ محلی به پورت ۸۷۶۶ را مجاز کند. |
| پورت اشغال است | سرور قبلی را متوقف کنید یا پورت دیگری بدهید و در آدرس مرورگر همان پورت را بنویسید. |

این بسته مستقل از Git تحویل داده شده است. تهیهٔ بسته، فایل‌های صوتی موجود یا سابقهٔ آن‌ها را از مخزن حذف نمی‌کند؛ بنابراین به‌تنهایی حجم پوش تاریخچهٔ قبلی را کم نمی‌کند.
