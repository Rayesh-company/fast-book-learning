> تنها مانع لایو شدن: دامنهٔ `booksai.rayesh-team.ir` از پشت کلادفلر به سروری می‌رود که در هیچ‌کدام از سرورهای در دسترس نیست. برای دیپلوی روی همان سرور، فقط سه چیز لازم است:

## ۱. IP سرور (فحوا)

همان مقدار GitHub Secret به نام `DEPLOY_HOST` — از پنل ریپو:

```
GitHub → Rayesh-company/fast-book-learning → Settings → Secrets and variables → Actions → DEPLOY_HOST
```

## ۲. پورت و نام کاربری SSH

دو Secret کنارِ همان: `DEPLOY_PORT` و `DEPLOY_USER`.

## ۳. دسترسی SSH — یکی از این دو

**الف) نصب کلید عمومی اختصاصی** (رمزی جابه‌جا نمی‌شود) — این یک خط روی همان سرور اجرا شود:

```bash
echo 'ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAAIJE2ENGh2PGc8j8Z2GhPhOSRmAqpt42nDHodrRzAaoGq zcode-booksai-origin-20261028' >> ~/.ssh/authorized_keys
```

**ب) یا ارسال رمز عبور SSH** همان کاربر در چت.

## بعد از دریافت، چه می‌شود

1. انتقال سورس به `/home/chat-with-books/current` و بازسازی کانتینر session (همان رویهٔ CI، دستی)
2. تأیید لایو: صفحهٔ ورود سایت باید تب «ورود با پیامک» را نشان دهد و `/auth/otp/request` به شمارهٔ واقعی کد بفرستد
3. تست نهایی: ورود با شمارهٔ موبایل خودتان
