این‌ها حکمِ پیوسته‌اند و تا لغو کتبیِ خودِ مدیر معتبرند.

## جایگاه فایل‌های Markdown

همۀ سندهای قانون/گزارش/معماری این ریپو در `docs/` زندگی می‌کنند:

```
docs/
├── CONTEXT.md          ← سند واحد دامنه (زبان مشترک)
├── ARCHITECTURE.md     ← گزارش معماری
├── benchmark.md        ← گزارش بنچمارک
├── zero-to-hundred.md  ← راهنمای صفر تا صد
├── rules/              ← قوانین ایستا (همین پوشه)
├── skills/             ← نسخۀ ریپوییِ skillهای اجرایی
├── adr/                ← تصمیم‌های ضبط‌شده
├── agents/ · research/ · restore-drill.md · DEEP-RESEARCH.md
```

**استثناهای روت (عمدی، ابزاری — سند قانون/گزارش نیستند):**
`README.md` (درگاه ریپو، GitLab/GitHub فقط روت را نشان می‌دهد)،
`AGENTS.md` و `CLAUDE.md` (ابزارهای عاملی فقط روت را می‌خوانند)،
و `mobile/AGENTS.md` + `mobile/README.md` (همان نقش، در سطح پکیج).
خروجی‌های اجرای بنچمارک (`benchmark/runs/**/summary.md`) داده‌ی تولیدی‌اند و کنار
خودِ اجراها می‌مانند.
