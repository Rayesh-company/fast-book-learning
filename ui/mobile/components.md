# اجزای رابط اجرایی موبایل

نسخهٔ تکمیل رابط، ۶ اکتبر ۲۰۲۶. رفتار مصوب در [ایشوی ۲۰](https://github.com/Rayesh-company/fast-book-learning/issues/20) است؛ قرارداد اجرا و محدودیت سرویس‌ها در [README](README.md).

رابط تک‌صفحه‌ای در `/mobile/`، پیش‌نمایش تعاملی در `/mobile/?demo=1` و طرح چندقابی اولیه در `/mobile/preview.html` قرار دارد. طرح تاریخی `docs/design/mobile-preview/` بدون بازنویسی حفظ شده است.

| جزء | رفتار اجرایی |
| --- | --- |
| پوسته | فارسی و RTL، فونت محلی وزیرمتن، رنگ‌های زمینهٔ کرم/تیره و اقدام سبزآبیِ طرح قبلی، استناد آبی |
| چت | منو راست، کتاب‌خوان چپ و عنوان وسط؛ پاسخ باز و حباب کاربر خنثی؛ انتخاب صفحه راست و میکروفون/ارسال چپ با ظاهر ثابت دامنه |
| پیام | زمینهٔ کتاب و صفحات ثابت برای هر پیام؛ توقف، خطا و تلاش مجدد؛ پایان سهمیه ارسال را نمی‌بندد |
| کتاب‌خوان | PDF اصلی و متن دقیق قابل انتخاب؛ ورودی پیش‌فرض پنهان؛ انتخاب + پرسش از ایجنت ورودی را باز می‌کند |
| پرسش روی کتاب | نقل‌قول زمینه، ورودی خالی، انتظار با توقف، پاسخ، ذخیره، کوچک‌کردن و بستن |
| پلیر جلسات | پلیر واحد پایین، پاراگراف قبلی/بعدی، لمس بدنه یا نگه‌داشتن دوثانیه‌ای برای بازشدن، زمان و سرعت در حالت بزرگ‌تر |
| انتخاب صفحه | دو چرخ مشترک جلسه/صفحه در کتاب‌خوان و چت؛ انتخاب موقت و تأیید، صفحات همان جلسه و گزینهٔ بدون جلسه |
| ناوبری | حفظ پیش‌نویس و صفحه؛ مقصد مشخص برای استناد و کارت مطالعه؛ سابقهٔ مستقل کتاب‌ها |
| منو | سابقهٔ امروز/هفته/قدیمی‌تر، حساب ثابت پایین، منوی شناور کنار سه‌نقطه برای تغییر نام و حذف با تأیید |
| دفتر | یادداشت/هایلایت، کتاب فعلی/همه، جستجوی متن و نظر، انتخاب گروهی و خروجی چاپ/PDF |
| یادداشت | متن ذخیره‌شده تغییر نمی‌کند؛ نظر شخصی قابل ویرایش؛ منبع و حذف در دسترس |
| حساب | شماره، اشتراک و سهمیه، نما مطابق دستگاه/روشن/تیره، خروج |
| ورود/پرداخت | فرم شماره/کد و حالت‌های نتیجهٔ پرداخت؛ خدمات تازه در نسخهٔ نمونه، سرویس دور بعد |
| ضبط | شروع، زمان، پایان، لغو؛ متن پس از پایان قابل ویرایش و ارسال دستی؛ خروج ضبط را متوقف می‌کند |

تصاویر واقعی رابط اجرایی در `docs/design/ui-complete-*.png` هستند. رفتار روی عرض‌های ۳۲۰ و ۳۹۰ و نمای عریض بررسی می‌شود؛ صفحه‌کلید دستگاه و ژست‌های لمسی به آزمون واقعی دستگاه نیاز دارند.
